# Khibi – Your Cute Coding Companion ❤️

Khibi is an interactive chibi desktop coding companion for VS Code. He lives in his own transparent, frameless Electron desktop window, wakes up when you open VS Code, celebrates your file saves and passing test suites, gets worried when new errors appear, and falls asleep after 5 minutes of inactivity.
