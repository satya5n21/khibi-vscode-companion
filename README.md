# Khibi – Your Cute Coding Companion ❤️

Khibi is an interactive chibi desktop coding companion for VS Code. He lives in his own transparent, frameless Electron desktop window, wakes up when you open VS Code, celebrates your file saves and passing test suites, gets worried when new errors appear, and falls asleep after 5 minutes of inactivity.

## Quick Start

1. **Install dependencies from the monorepo root:**
   ```bash
   npm install
```

## Choosing / making a character

Run **Khibi: Choose Character** from the Command Palette to switch instantly. Want your own? Drop a folder in
**Khibi: Open My Characters Folder** - see [docs/CHARACTER_GUIDE.md](docs/CHARACTER_GUIDE.md) for the pack format and
ready-to-paste Gemini / ChatGPT prompts.
